# <img src="https://cdn.simpleicons.org/aboutdotme/2563eb" width="20"/> Visão Geral

O **Radar Centrobor** é uma plataforma web corporativa desenvolvida para consolidar informações estratégicas da operação comercial em um único ambiente digital moderno, seguro e responsivo.

A solução foi projetada para proporcionar:

- Centralização de indicadores operacionais
- Monitoramento comercial em tempo real
- Gestão de metas e faturamento
- Controle de pedidos e oportunidades
- Comunicação interna integrada
- Dashboards personalizados por colaborador

Além disso, o sistema utiliza arquitetura **PWA (Progressive Web App)**, permitindo instalação em computadores e dispositivos móveis sem necessidade de publicação em lojas de aplicativos.

# <img src="https://cdn.simpleicons.org/googlechrome/2563eb" width="20"/> Instalação e Execução

## Clonando o Repositório

```bash
git clone https://github.com/centrobor/radarcentrobor.git
```

---

## Acessando o Projeto

```bash
cd radarcentrobor
```

---

## Execução Local

Utilize qualquer servidor HTTP local.

### Exemplo com Node.js

```bash
npx http-server
```

### Exemplo com VS Code

- Instale a extensão **Live Server**
- Clique com botão direito em `index.html`
- Selecione **Open with Live Server**
